# UTM_FSU_Math_Stats_Oncology
Repository for UTM and FSU to work on building resources to teach mathematical and statistical oncology

## Aims for Week 2

Introduction Chapter:

  - What is a mathematical model
  - Explain that a system of ODE’s can be used as a mathematical model
  - Review the Characteristic equation
  - Review the Jacobian
  - Summarize the stability based on the eigenvalues
  - Illustrative example: predator-prey
    - Predator: Immune cells
    - Prey: Tumour cells
    - Show equilibrium, calculate Jacobian, show the signs
    - Comment on how realistic this is (need someone with a stronger bio background)
